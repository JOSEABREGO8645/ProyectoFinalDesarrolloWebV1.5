1. Iniciar y cerrar sesión

  1. Abra https://libreria-san-francisco.onrender.com. Para demostración local: http://127.0.0.1:5176.
  2. Escriba su usuario y contraseña. Pulse Iniciar sesión.
  3. Verá Inicio con el mensaje de bienvenida y su sucursal activa.
  4. Use el icono Cerrar sesión al terminar, especialmente en equipos compartidos.

Si el acceso es rechazado, revise las credenciales y el estado de la cuenta. Después de varios intentos debe esperar. Solicite al administrador restablecer el acceso; el código de facturación no es la contraseña.

2. Inicio y navegación

La barra muestra los módulos permitidos. No ver un módulo puede deberse a su perfil; no significa que sus datos hayan desaparecido. Inicio siempre es la primera pantalla después de iniciar sesión. El botón de casa permite volver.

Cambiar de sucursal

Use el selector debajo de su nombre, arriba a la derecha. Solo aparecen sucursales activas disponibles para su cuenta. Al elegir otra se recargan los datos y el inventario de esa ubicación. Compruebe el nombre antes de cobrar, recibir mercadería o enviar/aceptar traslados. El cambio se bloquea mientras se guarda una operación.

El borrador de venta se separa por usuario y sucursal mientras la pestaña sigue abierta. Recargar o cerrar el navegador pierde los borradores sin facturar.

3. Usuarios y sucursales asignadas

  1. Entre en Usuarios y pulse Agregar usuario.
  2. Complete nombre, usuario y contraseña; asigne el código de facturación de cuatro dígitos.
  3. Elija rol, módulos permitidos, sucursal principal y las sucursales adicionales de trabajo.
  4. Guarde y entregue el acceso de forma privada. Nunca comparta el código entre cajeros.
  5. Para modificar el acceso, abra Editar. Los cambios de permisos/asignaciones pueden exigir iniciar sesión nuevamente.

Una cuenta empleada puede trabajar en varias sucursales autorizadas. Un superusuario dispone de las sucursales activas, pero también debe activar la ubicación correspondiente para operar. Las sucursales con usuarios o documentos relacionados no se eliminan libremente.

4. Productos, proveedores y clientes

  1. Registre primero el proveedor si recibirá productos asociados a él.
  2. En Catálogo, use Agregar producto y complete código, nombre, costo, precio, mínimo y proveedor.
  3. Conserve los ceros iniciales del código. Puede buscar por código, nombre o categoría.
  4. En Clientes, guarde nombre y NIT. El sistema normaliza el NIT al consultar y guardar.
  5. Los filtros de existencias cambian la consulta; no trasladan unidades ni modifican la sucursal activa.
Editar el producto no agrega stock. Use Ingresos para recibir mercadería y Traslados para moverla entre sucursales. La eliminación de registros referenciados puede ser rechazada para conservar el historial.

5. Registrar un ingreso

  1. Confirme la sucursal activa y entre en Ingresos.
  2. Abra un nuevo ingreso y seleccione un proveedor activo.
  3. Agregue productos de ese proveedor y sus cantidades.
  4. Revise el detalle y guarde. El sistema calcula el costo y aumenta el inventario de esta sucursal.
  5. Abra el documento para consultar o imprimir. Si corresponde, genere el comprobante de pago de prueba.

El pago de prueba no ejecuta una transferencia bancaria. Para corregir un ingreso ya registrado, un superusuario puede anularlo con motivo, siempre que exista stock para revertirlo. No borre el documento para cuadrar existencias.

6. Caja de ventas · agregar productos

  1. Entre en Ventas: la caja y el buscador ya están abiertos.
  2. Escanee el código y envíe Enter para una unidad.
  3. Para varias unidades, escriba cantidad*código y pulse Enter. Ejemplo: 5*000-DEMO-001.
  4. Para buscar por nombre, escriba parte del nombre y seleccione el producto.
  5. Revise o ajuste cantidades y quite líneas equivocadas antes de cobrar.

Un lector externo normalmente envía el código y Enter automáticamente. Se verificó ese comportamiento mediante teclado simulado; no se afirma haber probado un escáner físico. Si no existe el código o falta inventario, aparecerá un aviso y la línea no se agrega.

7. Cliente y revisión antes de cobrar

  1. Pulse Agregar cliente (NIT). Busque el NIT exacto o seleccione un cliente por nombre.
  2. Si no existe y tiene permiso de Clientes, use Registrar nuevo cliente.
  3. Si la compra no requiere cliente identificado, conserve Consumidor Final · CF.
  4. Revise cantidades, cliente y total. Pulse Guardar (facturar).
  5. Si cambiaron precios o existencias, revise el aviso y el detalle actualizado antes de seguir.

Guardar (facturar) abre el cobro; la venta todavía no queda registrada. Los precios finales se verifican nuevamente en el servidor.

8. Cobrar y autorizar

  1. Ingrese el efectivo recibido. Debe cubrir el total.
  2. Revise el cambio y pulse Confirmar cobro.
  3. En Autorizar venta, ingrese su código personal de cuatro dígitos y pulse Facturar venta.

Después del registro se abre el comprobante y la caja queda lista para la siguiente venta. Puede imprimirlo o solicitar la factura de prueba. Esa factura no tiene validez fiscal.

9. Traslados entre sucursales

  1. Active la sucursal de origen y cree un traslado hacia una sucursal distinta.
  2. Agregue productos disponibles y envíe. Las unidades salen del origen y quedan en tránsito.
  3. Para recibir, active la sucursal destino con una cuenta autorizada, abra el traslado y confirme.
  4. Para cancelarlo mientras sigue enviado, active la sucursal de origen y anule con un motivo.
Origen puede anular y destino puede confirmar. El administrador respeta la misma regla. Un traslado ya confirmado o anulado no vuelve a ejecutarse. Verlo en el historial no concede permiso para ambas acciones.

10. Dashboard

Seleccione sucursal y período para consultar ventas, ingresos, gráfica diaria y documentos recientes. Los indicadores de inventario son actuales; los movimientos y documentos usan el período elegido. Los traslados pendientes pueden haberse enviado antes de ese período y seguir en tránsito.

Puede usar accesos de siete o treinta días y fechas personalizadas, con máximo noventa días. Las opciones disponibles respetan sus módulos y sucursales. Un cero puede indicar ausencia de operaciones para ese filtro; no modifique saldos desde el Dashboard.

11. Reportes

Entre en Reportes, elija el tipo, ajuste los filtros disponibles y consulte. Para reportes con fechas, el período máximo es de 366 días. El empleado consulta su sucursal; el administrador puede seleccionar una o todas.

Exportar CSV descarga el resultado completo de los filtros. Imprimir prepara la vista consultada con su contexto; use Guardar como PDF del navegador si necesita un archivo. Verifique qué página está mostrando antes de imprimir una consulta paginada.

12. Recuperación y mensajes frecuentes

SituaciónQué hacer
Respuesta de venta inciertaNo cree otra venta ni cambie el detalle. Use Verificar venta registrada o Reintentar facturación de la misma operación.
Sucursal cambiadaRevise el nombre activo y recargue la consulta. La operación anterior no se envía automáticamente a otra ubicación.
Stock insuficienteCompruebe sucursal y cantidades. Si la mercadería está en otra ubicación, tramite un traslado.
Sin permisoSolicite al administrador revisar módulos y sucursales asignadas.
Código incorrectoUse su código de facturación. No pruebe códigos de otras cuentas.
Servicio externo no disponibleConserve el documento. Reintente la integración de prueba cuando vuelva a estar disponible.
Anulación rechazadaRevise estado, sucursal y stock necesario para la reversión.

Buenas prácticas de operación

  • Revise la sucursal al comenzar cada turno y antes de recibir traslados.
  • No comparta usuario, contraseña o código de facturación.
  • Use el historial para confirmar un resultado dudoso antes de repetirlo.
  • Cierre sesión al terminar. Contacte al administrador si detecta saldos o documentos inesperados.
